What is this company worth?

There isn't one valuation model — there are families. Intrinsic models (DCF, DDM, Excess-Return) value the company from its own cash flows; relative models (Comps) value it from what the market pays for peers. The most common real-world error is running the wrong model on the wrong company — so picking the model is the first lesson.

3 quick questions — we'll recommend a model

Is it a bank, NBFC or insurance company?
Is it IPO-ing now / listed only recently?
Does it pay steady, meaningful dividends?
